## How to Use Each File

All files follow this pattern:

1. **File naming:** `[service-name]-body-wp.html`
2. **Content:** HTML only (WordPress-safe)
3. **Sections:** Hero → Overview → Process → Results → Pricing → FAQ → CTA
4. **Styling:** Inline CSS, fully responsive, dark neonspec theme
5. **JavaScript:** FAQ accordions + progress bar

### To Implement:
```
1. Go to WordPress → Pages → [Page Name]
2. Add Custom HTML block
3. Copy entire content from the -body-wp.html file
4. Paste into WordPress
5. Update Rank Math SEO (focus keyword + meta description)
6. Publish
```
