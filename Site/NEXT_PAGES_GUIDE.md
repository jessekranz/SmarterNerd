## Quick Build Workflow

For **each page**, follow this pattern:

1. **Create Page in WordPress:**
   - Pages → Add New
   - Title: [from above]
   - Slug: [from above - lowercase, no spaces]
   - Template: "Custom Full Width (Neonspec)"

2. **Add Content:**
   - Click **"+"** button
   - Search for **"Custom HTML"**
   - Open the corresponding HTML file from your `/Site/` folder
   - Copy from `<div class="progress"></div>` to the last `</section>` (STOP before `<style>`)
   - Paste into Custom HTML block

3. **Set SEO (Rank Math):**
   - Copy Focus Keyword from above
   - Copy Meta Description from above
   - Check green checkmark

4. **Publish**

5. **Test:**
   - Click View Page
   - Check on mobile (F12 → device toggle)
   - Verify all links work
