## Structure

Each service page file includes:

1. **Hero Section** — Service name, benefit, description
2. **Overview Section** — What the service is, why it matters, benefits list
3. **Process Section** — 4-step how-we-do-it walkthrough
4. **Results Section** — 3 key results/metrics with examples
5. **Pricing Section** — 3-tier pricing with features (Starter/Pro/Enterprise or similar)
6. **FAQ Section** — 6 common questions (expandable)
7. **CTA Section** — Call to action (schedule consultation)
8. **Styling** — All CSS included, fully responsive
9. **JavaScript** — FAQ accordion + progress bar

## Implementation

For each service page:

1. Go to **WordPress → Pages → [Service Name]**
2. Edit the page (or create new if doesn't exist)
3. Delete old content
4. Add **Custom HTML block**
5. Copy entire content from the corresponding `-body-wp.html` file
6. Paste into WordPress
7. Update **Rank Math SEO**:
   - Focus Keyword: `[service] Fort Lauderdale` (e.g., "web design Fort Lauderdale")
   - Meta Description: Service-specific, 155-160 characters
8. **Publish**
